# MookDoctorC

MookDoctorC 是本地 Android TXT／EPUB 阅读器、CLM 2 播客和本地音乐播放器。包名为 `local.bookdoctorc`，当前版本为 1.0.24+33，版本码为 33，支持 Android 8.0（API 26）及以上。

[维护文档](维护文档.md) · [设定记录](设定记录.md) · [FileDoctorC 迁移接口](FileDoctorC迁移接口.md)

## 安装与升级

在 Releases 下载 MookDoctorC-1.0.24+33.apk。Windows 的 CLM Studio 0.2.1+5 安装包在同一 Release。从旧版 MookDoctorC 或兼容的 BookDoctorC 版本升级时，直接打开 APK 并确认覆盖安装。新版沿用原包名和签名，原应用数据仍在同一个 Android 应用中。若书籍或音频提示授权失效，从「我的」重新授权原目录。换机请使用模块迁移。

新版书架和播客按 HTML 原型落地，启动图标换为 Q 版立体书本。底栏把图标与文字作为一组居中，选中框随切页滑动，两者同时变色。

## 使用

- 在「我的 → 导入图书」进入内置文件浏览。首次点击「授权目录」由 Android 授予文件夹访问权。可直接点选文件、从右侧勾选区域滑过多行，或用「全选本层」选择当前文件夹内的 TXT／EPUB。选中的书进入同一木匣。
- 书架大卡展示总藏书和今日阅读时长。「最近阅读」位于大卡内，打开后可看最近六本。按实际分类浏览，书籍格式右侧的圆环显示整本阅读进度。
- 右上角搜索书名和作者。分类内可排序、切换封面和列表显示，长按分类可管理原书匣。
- 点中书卡、搜索结果或阅读记录，整张入口卡片先展开成阅读页，正文准备好后接入。退出时收回同一位置，平板横屏的书封沿脊翻开。书架、播客、音乐、记录和我的之间整页横移，可轻点或长按拖动后松手确认。
- 阅读正文中，点按顶部 23% 整带，或点按高度 23% 至 40%、宽度 35% 至 65% 的中央区域，会打开选项。其余区域以宽度 35% 为界，左侧向前，右侧向后。连续滚动模式每次移动近一屏。
- 阅读选项按排版、阅读与书签、书籍与文件折叠。在「排版 → 字体」可导入一个 TTF 文件并立即应用。再次导入会替换上一份本地字体。排版也可调整字号、行距、段距、页边距和首行缩进，设置随本地备份保存。搜索正文可查找本书文字，点击结果会连续收起搜索和阅读选项，直接显示命中正文；跳转后可通过悬浮栏返回跳转前的位置，也可关闭悬浮栏继续阅读。
- 「记录」按设备当地日期显示阅读和听书时长。点双箭头图标在已启用模块间循环。点日期查看对应书籍或唱片的封面和时长。播客热力图的日期摘要显示当天播放的唱片封面。阅读和听书占比保留百分比数字，并用横条显示。切回记录时保留当前模块、日期和滚动位置。
- 在「我的 → 目录规则」勾选 TXT 标题样式，卷支持折叠。EPUB 直接读取内置目录。阅读与书签分组提供竖向连续滚动、横向平移、横向单页和书签。
- 「我的 → 替换净化规则」可保存文字查找和替换，替换值留空时删除命中文字。选择一本书查看命中数并确认写回。阅读页「选项 → 书籍与文件 → 替换净化规则」直接对当前书应用规则，写回后重新载入正文。EPUB 按文字节点匹配，保留标签和其他归档条目。
- 长按书封进入书籍操作卡，可阅读、编辑信息、导出或移除。阅读选项的「书籍与文件」也提供「编辑信息」。
- 在「编辑信息」更改标题、作者和内容简介。「书籍封面」可从本机导入。选中封面后先预览，点击「保存」一起提交。TXT 和 EPUB 的默认导出名分别为「标题 作者：姓名.txt」和「标题 作者：姓名.epub」。缺少作者时使用「未标注」。原格式导出逐字节复制源文件。TXT 转 EPUB 时使用已保存的书籍信息和封面，EPUB 也可导出为 UTF-8 纯文本。
- 「我的 → 备份与恢复」保存本地 ZIP，包含书架、书籍资料、引用、进度、书签、阅读和听书时长、封面、导入字体和规则。恢复合并记录，原书正文继续由源文件管理。新设备或目录访问权失效时需重新授权源目录。

## 播客

先在「我的 → CLM 内容口令」输入封装时使用的口令，再授权播客文件夹。升级后，已有 CLM 2 使用原口令即可播放。应用一次记住一个口令，通过 Android Keystore 加密保存，备份和 FileDoctorC 模块迁移均排除该口令。换机后在新设备重新输入。关于封装步骤、分块和跳转机制，见 [CLM 制作与格式](clm-studio/README.md)。

- 在「我的 → 播客文件夹」授权后递归扫描 CLM 2。按源目录对应的系列和 CLM 文件浏览。宽屏横向并排显示系列与节目，窄屏上下排列。播客与音乐共用底部悬浮播放条。
- 首页固定显示录音机主图，大卡标题显示上次实际播放的「节目名·第几集」。集数取自该 CLM 文件内的音轨顺序。点「继续收听」接上原断点，点「最近收听」可查看最近六项。第一次使用时，大卡显示「暂无播放记录」。
- 支持断点续听、拖动进度、上一集、下一集、连续播放、0.5–2 倍速及跳过片头片尾。听书时长按实际播放时间累计，暂停和缓冲时停止计时。
- 播放页使用听音室的桌面近景、俯视金属唱机和两组玻璃控件。播放时唱片标签随黑胶转动，唱臂移入后落针。暂停时唱臂抬起并回到右侧。从节目列表或「继续收听」打开播放器。章节目录和播放设置通过局部浮窗打开。
- 开始播放后，Android 系统媒体卡片显示音轨名、专辑、内嵌封面与进度。可以在通知栏或锁屏暂停、继续、选集或拖动进度，点媒体卡片可回到播放页。离开应用后，当前播放由媒体服务继续。

## 音乐和模块迁移

音乐播放器点封面原位查看无边框歌词。点歌词文字跳播，点空白或曲目信息右侧按钮返回封面。播放模式通过图标循环切换。音乐记录按实际播放时间绘制月度热力图，可点日期查看当天曲目。支持 3008×1880 平板横屏布局。

- 在「我的 → 音乐文件夹」授权。每个直接包含音频的文件夹形成歌单，打开应用会在后台检查新增文件。首页曲目随机分批展示，歌单内提供文件名和添加时间两种排序。
- 播放器读取内嵌封面和歌词。有时间戳的歌词可点按跳转。顺序播放从当前歌单进入下一张，列表循环在当前歌单回绕。小随机在当前歌单抽取，大随机在全部曲目抽取，优先考虑常听曲目。
- 已读取的音乐封面保存在应用内。返回音乐首页、重新打开歌单或播放器时，命中的内存封面直接绑定到界面。应用重启时优先恢复已有曲目和首批缓存封面，并在后台扫描目录更新。新曲目或源文件版本改变时读取对应音频。
- 点曲目会打开该条目对应的音频。有效的播放记录可以续播，已到曲尾的记录会从头播放。
- 在「我的 → 用 FileDoctorC 迁移」勾选模块并交给 FileDoctorC 1.1.5+30 或后续兼容版。接收设备在 FileDoctorC 打开迁移文件即可恢复，也可在 MookDoctorC 中点「我的 → 用 FileDoctorC 迁移 → 恢复迁移文件」手动选择。源文件和记录被一起复制到接收端应用资料库。

## 源文件与联网

Android 文档 URI 是书籍入口。TXT 读取源流，EPUB 通过可定位的描述符读取原 ZIP。可写来源支持将文字编辑写回。写回前生成可从阅读页导出的修改前备份。EPUB 仅替换所选文字范围，逐条核对未改条目的压缩数据。带数字签名的 EPUB 拒绝编辑。TXT 上限 24 MB、EPUB 上限 256 MB、单页 XHTML 上限 8 MB。

封面从本机导入。编辑信息更新应用内的书籍资料，源 TXT／EPUB 保留原有字节。正文浏览器屏蔽远程请求。书源、联网正文、RSS、云同步及原版深链已剔除。

## Windows · CLM Studio 制作器

在 CLM Studio 中选择音频、调整顺序、选择 JPEG／PNG／WebP 封面，输入自己保管的内容口令。点击「生成 CLM 文件」，输出文件名用作节目标题。制作器按最终列表顺序封装原始音轨。将文件放到手机的播客目录，用相同口令播放。

[制作步骤、命令行入口和 CLM 2 二进制格式](clm-studio/README.md)

## 构建

在工作区 PowerShell 中运行 `& .\build-local.ps1`。指定 `-SignedApk <绝对路径>` 使用工作区公用 PKCS#12 的 `bookdoctorc` 别名签名。Gradle Wrapper 9.5.0、AGP 9.2.1、JDK 17、SDK Platform 37 和 Build Tools 37.0.0。缓存写入工作区 `.cache/MookDoctorC-build-1.0.24+33`。

Android 源码可在没有内容口令的情况下编译。独立克隆后设置 JDK 17 和 Android SDK Platform 37，在仓库根目录运行 gradlew.bat :app:assembleRelease。覆盖安装需要原发行签名，设备上的内容口令凭据由用户单独设置。
