# CLM Studio 与 CLM 2

CLM Studio 是 MookDoctorC 配套的 Windows x64 音频归档制作器。把一组有顺序的音轨、一张封面和一个节目标题打包成单个 .clm 文件，适合存放播客系列、广播剧或分集有声书。Windows 安装包和 Android APK 位于同一个 GitHub Release。

## 制作并导入

1. **整理音频。** 准备本机音轨，一套节目可以包含多集。尽量采用手机能解码的格式，例如 MP3、M4A 或 AAC。封装保留输入的音频编码和字节，播放能力由手机解码器决定。
2. **添加并排序。** 点「添加音频」多选文件。首次按文件名自然数字排序，让第 2 集排在第 10 集前。可拖动条目手调，按最终可见顺序播放。达到 100 项时，可识别的集号至少显示三位，这只影响归档中的名称。
3. **选择封面。** 选一张可预览的 JPEG、PNG 或 WebP，最大 8 MiB。封面随音轨打包，手机端可显示在节目列表和媒体卡片。
4. **输入内容口令。** 在制作器的「内容口令」中输入自行保管的口令。需要一起收听的一批 CLM 可使用同一个口令，MookDoctorC 当前一次保存一个。旧 CLM 2 直接使用原封装口令。旧 CLM v1 是早期 ZIP 容器，需要用原音频制作新的 CLM 2。
5. **生成归档。** 点「生成 CLM 文件」并选择保存位置。文件基名用作标题。保留源音轨以便重新排序或重新封装。
6. **手机播放。** 把 .clm 复制到本地播客目录，进入 MookDoctorC 的「我的 → CLM 内容口令」输入同一口令，再在「我的 → 播客文件夹」授权该目录。应用递归扫描，按实际子目录分组。可切集、拖动、调倍速、跳过片头片尾，并在锁屏继续控制播放。

「用 FileDoctorC 迁移」可以复制播客源文件和听书记录。接收设备的 CLM 口令需单独输入。使用本地可随机读取的文档位置，便于播放器按偏移读取。

## 归档怎样写入和播放

| 部分 | 读写约定 |
| --- | --- |
| 固定头部 | 64 字节。依次记录魔数 CLM2ENC 和 NUL、版本 2、块大小、派生迭代数、目录长度、16 字节随机 salt、12 字节随机目录 nonce 和保留字段。头部没有内容口令。 |
| 容器密钥 | 用本次输入的口令和文件 salt 经 PBKDF2-HMAC-SHA256 派生 32 字节 AES 密钥，迭代次数为 210,000。再次封装会生成新的 salt。 |
| 目录 | UTF-8 JSON 描述标题、封面和有序音轨，各条目含相对偏移量、原始长度、MIME 和随机 nonce 前缀。目录用 AES-256-GCM 加密和认证，原始 64 字节头部作为附加认证数据。 |
| 封面和音轨 | 按目录顺序连续排布，每块最多 64 KiB 明文，每块末尾追加 16 字节认证标签。块 nonce 为条目的 8 字节随机前缀与 4 字节大端块号。块认证数据绑定容器魔数、条目序号、块号和明文长度。 |
| 进度和跳转 | MookDoctorC 认证目录后读取封面。Android Media3 请求音频字节时，读取器按偏移定位并验证所需密文块。拖动播放位置可直接读取目标块，音轨无需整份解包至磁盘。播放记忆按容器 salt 标识，重新封装会生成新标识。 |

目录上限 4 MiB。音轨数最少 1 条、最多 100,000 条，且受目录大小限制。封装器按块写入同目录临时文件，成功后替换目标。源音频不改名、不转码。口令不匹配或认证失败时，Android 会拒绝解密相关数据。完整字段偏移和边界条件见 [CLM 2 协议](CLM2-格式.md)。

## 构建与自动化

- 桌面使用 .NET 8 SDK、WPF、Inno Setup 6。运行 installer/build-installer.ps1，可用 -DotnetPath 和 -InnoSetup 指定本机工具。输出为 Windows x64 自包含安装包，原安装身份沿用。
- 命令行使用同一个写入实现。由当前进程的 CLM_CONTENT_PASSPHRASE 环境变量提供本地口令，参数依次为输入文件夹、封面、输出和标题。

    dotnet run --project ./tools/ClmPack -- pack ./audio ./cover.png ./show.clm "节目标题"

- fixture 子命令生成只用于跨端测试的合成封面和三条字节流，分别覆盖跨块、整块和不足一块的情形。

项目路径下的源码、构建产物和 GitHub 发布件均无生产内容口令。Android 在运行时接收口令，Windows 图形界面中的口令只在本次运行时使用。

安装包随附所用 Microsoft .NET 和 Windows Desktop 运行时的许可证与第三方声明，安装后可在程序目录的 licenses 子目录查看。
