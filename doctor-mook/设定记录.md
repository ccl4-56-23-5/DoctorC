# MookDoctorC 设定记录

归档规范生效日期：2026-11-12。本文件从本次对话的明确要求与现有维护文档接续；早期未给出日期的要求按实现版本标识，不补造日期。维护时与同目录《维护文档》一起读取，新的用户决定优先。

## 产品与数据

- Android 本地 TXT／EPUB 阅读、CLM 2 播客与本地音乐。书架、封面、阅读位置、书签、播放断点和时长存于应用资料库。用户授权的编辑操作可以写回源文件，导出由用户选择目标。
- 主题、排版和阅读位置随原应用覆盖升级保留。更新沿用bookdoctorc签名别名；秘密只在工作区密钥登记，不写入源码和文档。
- 阅读点按边界（1.0.1起）：Y<23%全宽打开菜单；23%≤Y<40%且35%≤X<65%打开菜单；剩余X<35%向前，否则向后。`tools/阅读页三区调节.html`是用户曾要求交付的可重复使用校准工具，不是临时验收脚本；演示默认值与实际应用边界以维护文档说明为准。

| --- | --- |

| 播客与唱机 | 1.0.20+29 起以 HTML 预览的录音机大卡、系列和节目列表为首页。播放器沿用独立的蓝色系日夜场景和 Runwell 三渲二图层。旧唱片匣口径见对应版本条目。 |
| 动效维护，1.0.8+14起 | 入口展开、返回收回同一实际来源；按PiliPlus一镜到底实例衔接位置、尺寸和圆角。书卡点击首帧即响应，文档后台准备，转场后再挂载WebView。禁止用前景渐隐替代连续变形；返回途中反向须接续当前可见状态。 |

| 首页控件与搜索 | 1.0.20+29 起书架大卡展示藏书总数和当日阅读时长，播客首页展示节目数量和收听时长。两页的右上角均保留搜索。更早的 CD 首页控件条款随新版原型更新。 |
| 记录页 | 统计包含CD封面；从其他模块回来不能只显示半截，保留滚动和选择状态；百分比同时有横向占比条。 |
| Android媒体卡，1.0.9+15 | 参考PiliPlus元数据和播放指令，把现有播放链接入MediaSession/MediaStyle；展示封面、曲目和进度，支持暂停/继续/切集/点卡回播放器。 |
| 动效时间 | 560 ms 和 410 ms 为层级开合、平级切换的参考时长。自 1.0.14+23 起，运行时按参考时长除以 1.10 并取整。连续变形两向采用对称曲线，途中反向接上当时的可见轮廓。 |

### 旧版 CD 首页设定

1.0.19+28 及此前的 CD 首页以唱片匣陈列。匣内和最近播放使用拟物黑胶及圆形封面，封面半径为唱片半径的 90%。播放器和陈列自 1.0.12+18 统一为蓝色系。早期 CD 首页精简路径、数量和「打开 CD」等控件，移除 CD 搜索，匣内关按钮使用无外框的「×」。这些首页形态保留在对应版本的源码中。

## 维护、交付和归档

- 普通更新递增末段和累计+N，平台versionCode独立递增；仅归档/补文档不升应用版本。历史提交及原APK代码提交保留可追溯。
- 2026-11-12工作区新规则覆盖旧文档“仅保留最新APK和验收截图”的条款：无指定GitHub仓库时保留最近两个已交付普通版本的完整源码、各自正式安装包及两份根目录文档；基线单独保留。
- 测试源码保留。测试/验收记录、日志、截图、录屏、临时脚本、项目构建缓存不留档，也不作为封包旁附件。清理使用回收站；保留Git历史、签名、SDK、模拟器运行环境、已安装软件及其用户数据。
- 先读源码和实际调用链，用现有自动测试或定向检查验证；只有必须核验系统交互或渲染时再用隔离设备。不得把模拟器验证说成真机验收。
- 用户明确要求封包时使用 Bandizip，保留隐藏文件及实际 Git 历史。完整性测试后实际解压，对照相对路径、文件大小、SHA-256。临时校验产物完成后清理。

## 1.0.11+17新增要求与处理状态（2026-11-12）

- “最近读书仍是1∶0.618”：记录页42×68的小书及页边已改为共用书架宽高比1∶√2；首页原已使用该比例，不再单独写死缩略图比例。
- 首次开软件点书架卡顿：复用未改变的书架页面；书封后台解码缓存；木纹/书脊硬件录制；书架模糊背景提前后台生成。已改善隔离模拟器采样，仍不能保证所有设备无长帧。
- CD开匣像揭盖并上移图标：由CdCrateMotion接管，入口每张方形封面移动到同一专辑的黑胶位置并变圆。删除此路径的整图上移裁切交接；风格和速度参照用户肯定的书匣。不能再按网格下标错误配对返回目标。
- 图书搜索结果点击直达阅读：正文命中后连续收起搜索与阅读选项两层，显示高亮和“回到搜索前位置”；书名结果直接展开并续读。不要只关闭搜索页而把正文留在选项后面。

## 1.0.11+17 验收边界

- 1.0.11+17 通过 23 项单元测试和隔离 Android 15 交互验证。
- 首开流畅度、CD转场观感以及液态玻璃最终材质仍待用户实际设备确认；不得记为用户已满意或把残余长帧写成完全消除。
- 1.0.11+17 归档阶段仅补文档和整理目录。

## 1.0.12+18 新增要求（2026-11-13）

- 用 Runwell 三渲二图层替换播放器唱机。播放器、目录、设置跟随 CD 模块的蓝色系。收纳态唱片架与展开匣使用同主题的冷蓝金属和衔接明度。
- 最近、匣内和听书记录的唱片在 560 毫秒内从实际触发位置连续变形到唱盘，返回同一来源。唱片随页面轮廓共同变形，禁止恢复向地平线裁走唱片的效果。
- 书架、木匣及阅读页的右上角使用放大镜。正文搜索独立于阅读选项，点击结果直接定位，保留高亮和回到搜索前位置。书名及作者搜索点击结果直接打开书籍并续读。
- 正文点按区打开的阅读选项改为 240 毫秒非线性淡入和短位移。这类无固定来源的临时界面可用普通非线性过渡。书卡、唱片、书匣和唱片匣继续从各自入口展开并收回。

## 1.0.13+22 新增要求（2026-11-18）

- 正式版从 `1.0.12+18-基线1` 派生，沿用书卡、唱片和匣子的基线过渡动画。金标联盟实验停止。清理范围限于本地实验源码、交付件、库和含实验产物的旧归档。现有基线单独保留，远端仓库维持原状。
- 日间和夜间使用同一听音室、同一机位和布局。时间通过自然光、窗外景色的明暗和室内台灯表现。播放器与 CD 陈列统一为蓝色系，使用生成的位图背景。
- 唱头为通透的半透明外壳，有两个安装孔，唱针位于唱头下方。删除右侧外伸拨片。机身用方向拉丝和边缘反光表现金属，唱头用清晰棱边反光和内部透射表现晶体质感。
- 控制面板亮部面积，保留中间调和拉丝纹。唱头的孔和针尖需要定向补光。以正常手机尺寸仍能辨认安装孔和边缘为视觉验收目标。

## 1.0.14+23 新增要求（2026-11-18）

- CD 日间图表现明确的日光方向、窗框投影和实际材质颜色。书架也提供同场景、同机位的独立日间与夜间照片。音频播放页采用听音室的独立桌面近景，场景和色系与 CD 陈列衔接。
- 章节目录和播放设置用局部浮窗，播放器仍可见。点章节关闭窗口并切换曲目。系统返回、关闭按钮和点击窗口外均可取消。
- 黑胶在陈列、唱片匣及播放器上都要有可辨的盘厚、盘缘和压制沟槽。唱标不遮住大部分沟槽。
- 修复 CLM 播放页返回唱片匣以及合上唱片匣时的突兀加速。完整相向开合共用时间曲线和时长，交互中断从当前可见位置接续。界面动效相较上一版统一提速 10%，同时保留非线性起止缓动。

## 1.0.15+24 新增要求（2026-11-18）

- 修复冷启动后首次触发过渡时的掉帧。把背景和唱机解码、整页模糊准备、统计查询及木匣深处的封面构建安排在转场之外。首次和重复触发分别按相同路径取样，真机刷新率和首帧观感以实际设备为准。
- 章节目录及播放设置保留局部窗口。目录用章节序号和「当前」标记建立层次。设置中播放倍速可滑动或键入，片头与片尾控件保留精确秒数，保存操作在窗口底部固定显示。

## 1.0.16+25 新增要求（2026-11-19）

## 1.0.17+26 新增要求（2026-11-20）

- 从正式版 1.0.16+25 向后更新。CD 改名为「播客」，增加独立音乐入口。底栏五枚线稿使用预览的位图素材。
- 「我的」设置书架、播客、音乐的启用状态及启动首页。记录点击「切换模块」在已启用项目中循环，用短距离平移和淡入衔接。书架移除最近阅读陈列，播客保留唱片陈列并移除「最近播放」标题。
- 图书导入和播客、音乐目录选择集中在「我的」。可以向既有木匣补充图书。音乐每次进入前台静默扫描已授权目录，每个直接含音乐文件的目录生成独立歌单。曲目随机排列并逐批追加。歌单可按文件名、首次发现时间升降序排序。
- 音乐与播客使用统一悬浮播放栏与媒体会话。音乐封面及歌词读取文件内嵌标签，可点有时间戳的歌词跳播。顺序播放跨歌单且在最后停止，列表循环在当前歌单内回绕。小随机限当前歌单，大随机覆盖全部。随机在本次进程内排除已播放和已抽到曲目，播放次数用于计算权重。
- 所选模块的源文件及对应记录一并通过 FileDoctorC 局域网传输。接收后恢复到本机资料库。书架携带木匣、书签和阅读记录，播客携带节目、断点和收听记录，音乐携带原始文件、目录归属、加入时间、进度、次数及历史。原设备的文件和记录保留。
- 本轮交付签名 APK。源码维护 ZIP 仍按需制作。
