# FileDoctorC

## 目标

在 Android 上从同一套文件浏览和搜索界面完成压缩、解压、重命名和设备间文件互传。文件管理各处保持一致的视觉层次和交互反馈。

## 约束

- C1. 首页底栏、独立搜索圆和搜索结果操作栏采用 RikkaHub/Haze 2.1.0 的固定强效果，保留清晰边缘折射、独立前景和连续变形。应用无需强度设置。
- C2. 无线和有线目标共用设备列表、接收确认、进度与落盘流程。识别到双方可达的有线连接时显示单独的设备卡片，用右上角线缆图标区分。两台 Android 手机直接通过 USB 线相连时，支持主机与配件模式在同条连接上双向传输。
- C3. 短按批量重命名规则立即打开已有规则，并将焦点和可视位置移到最直接决定产出名称的字段或选项。
- C4. 继续使用当前应用 ID、签名和数据格式，以便设备可覆盖更新并保留原有设置、规则和书签。

沿用上级软件工程工作区规则。以源码根目录的 维护文档.md 为重建入口，以 设定记录.md 接续已确认的历史要求。
